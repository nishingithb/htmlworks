What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure the framework of all web pages on the internet.


What is CSS?

It is a stylesheet language used to control the visual presentation, layout, and design of web pages written in HTML. Along with HTML (content structure) and JavaScript (interactive behavior), CSS is one of the core foundation technologies of the World Wide Web.


What is Javascript?

JavaScript is a high-level, versatile programming language that powers interactivity and dynamic behavior across the internet.


What is bootstrap?

The term bootstrap originates from the phrase "to pull oneself up by one's bootstraps", meaning to achieve something without outside help. Today, its meaning depends entirely on the industry you are referencing
